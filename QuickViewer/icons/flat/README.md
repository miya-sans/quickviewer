# Flat icons

Monochrome toolbar and menu icons. QuickViewer colors them for the current theme at runtime,
so they are drawn in a single color here.

- Copied from [nomacs](https://github.com/nomacs/nomacs) (`ImageLounge/src/img`), licensed under the
  GNU General Public License v3, the same license as QuickViewer:
  `bars`, `copy`, `dir`, `export`, `find`, `fit-width`, `fullscreen`, `info`, `next`, `open`, `pin`,
  `play`, `previous`, `rects`, `rotate-cw`, `settings`, `sliders`, `star-off`, `star-on`, `trash`, `up`,
  `zoom-in`, `zoom-out`, `zoom-reset`
- Drawn for QuickViewer in the same style:
  `chevron-down`, `chevron-right`, `chevron-up`, `close`, `dualview`, `first`, `home`, `last`, `next-fast`, `plus`, `previous-fast`, `save`,
  `subfolders`, `volume-next`, `volume-previous`
